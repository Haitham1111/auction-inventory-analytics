# data/

## Raw (`raw/`)

Original exports from LocalAuctions.com, untouched:

- `home_kitchen_auction_23154_results.xlsx` — full results for the Mar 28, 2026 Home & Kitchen liquidation auction (162 lots). Note: the export has several junk header rows (address block, title) above the real table; `analysis/auction_analysis.py` skips them.
- `pallets_auction_23166_results.xlsx` — results for the Mar 28, 2026 Pallets liquidation auction (6 lots). Same export format.
- `auction_23613_items_list.csv` — item-listing/consignment template (13 rows): how lots are described, categorized, and listed before auction.

## Cleaned

Generated by `analysis/auction_analysis.py` — one row per lot:

| Column | Meaning |
|---|---|
| `lot` | Lot number |
| `title` | Lot title (often includes the advertised retail price) |
| `buyer_id` | Anonymous numeric buyer ID from the auction house |
| `quantity` | Quantity sold in the lot |
| `hammer_price` | Final hammer price in USD |

- `home_kitchen_results_clean.csv` — 162 lots
- `pallets_results_clean.csv` — 6 lots

Buyer IDs are the auction house's anonymous bidder numbers — no personal information.
